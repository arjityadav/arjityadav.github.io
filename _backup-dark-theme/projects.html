EU AI Act Compliance Copilot

A multi-agent RAG system that classifies AI systems under the EU AI Act and maps their obligations, deadlines and compliance gaps.

Live demo Source on GitHub

$0hosting cost

How it works

  • LangGraph pipeline with a clarifying-question step, parallel LLM and ML classification, and a writer–verifier loop capped at three attempts.
  • Hybrid retrieval over the full Act (292 structure-aware chunks) with pgvector, Postgres full-text search and Reciprocal Rank Fusion.
  • Citations, legal rules and deadlines are checked in code rather than trusted from the model, with prompt-injection and PII guardrails in front.

What moved the numbers

  • A 20-scenario eval suite drove the fixes: one run showed the verifier rejecting correct reports, and moving that step into code cut assessment time by 57%.
  • An Annex III classifier acts as an independent second opinion, with an MLflow registry, a promotion gate and drift monitoring. Hand-reviewing 270 synthetic rows (43 relabelled, 72 removed as wrong or leaking) took macro F1 from 0.22 to 0.73.

How it ships

  • Runs on Oracle Cloud with Docker Compose, Caddy and a Streamlit UI, using gpt-oss-120b on Groq.
  • GitHub Actions runs integration tests against real Postgres and Redis; the server deploys green commits and rolls back unhealthy releases on its own.
