P.01 — MULTI-AGENT RAG LIVE DEMO SOURCE

EU AI Act Compliance Copilot

A multi-agent RAG system that classifies AI systems under the EU AI Act and maps their obligations, deadlines and compliance gaps, from retrieval and evals to the server it runs on.

0.90recall@5, vs 0.42 keyword-only
57%faster assessments
0.22 → 0.73classifier macro F1
$0hosting cost

How it works

  • LangGraph pipeline with a clarifying-question step, parallel LLM and ML classification, and a writer–verifier loop capped at three attempts.
  • Hybrid retrieval over the full Act (292 structure-aware chunks) with pgvector, Postgres full-text search and Reciprocal Rank Fusion.
  • Citations, legal rules and deadlines are checked in code rather than trusted from the model, with prompt-injection and PII guardrails in front.

What moved the numbers

  • A 20-scenario eval suite drove the fixes: one run showed the verifier rejecting correct reports, and moving that step into code cut assessment time by 57%.
  • An Annex III classifier acts as an independent second opinion, with an MLflow registry, a promotion gate and drift monitoring. Hand-reviewing 270 synthetic rows (43 relabelled, 72 removed) took macro F1 from 0.22 to 0.73.

How it ships

  • Runs on Oracle Cloud with Docker Compose, Caddy and a Streamlit UI, using gpt-oss-120b on Groq.
  • GitHub Actions runs integration tests against real Postgres and Redis; the server deploys green commits and rolls back unhealthy releases on its own.

P.02 — RESEARCH · M.SC THESISVIS INSTITUTE · UNIVERSITÄT STUTTGART · 2025–26

Energy-efficient semantic segmentation using spiking neural networks

An ultra-lightweight Spiking U-Net for segmenting driving scenes, the kind of event-driven network the animation at the top of this page is a nod to. Population coding with direct training gets competitive accuracy in a single timestep (T=1), sidestepping the usual SNN trade-off between latency and accuracy.

500Ktrainable parameters
17×smaller than the prior spiking state of the art
~45%lower estimated hardware power vs. the ANN
1.86%from the ANN baseline on DDD-17 events

What was compared

  • Three ways to get a working SNN: direct spatiotemporal backpropagation (STBP), post-training ANN-to-SNN calibration, and a two-stage hybrid that calibrates and then fine-tunes.
  • Tested on data of increasing difficulty: synthetic CLEVR scenes, noisy Cityscapes driving frames and native neuromorphic event streams from DDD-17.

What it found

  • Calibration and hybrid methods hold up on synthetic data but break down under real-world driving noise.
  • Replacing noisy temporal rate coding with spatial redundancy (population coding) and training directly with STBP fixes this at T=1.

Why it matters

  • 68× smaller than the ANN baseline, and roughly an order of magnitude better than existing single-neuron SNNs at detecting dynamic targets such as pedestrians.
  • A practical route to real-time perception on low-power neuromorphic hardware.
